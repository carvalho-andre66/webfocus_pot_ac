# 4_transpilation

Translate the business logic in WebFOCUS report procedures into a LookML semantic layer.

The Proof of Technology implementation lives in [`pot/`](pot/README.md). Run it with:

```bash
uv run python 4_transpilation/pot/main.py --run-id RUN_ID
```

`uv run python 4_transpilation/main.py --run-id RUN_ID` calls the same entrypoint.
